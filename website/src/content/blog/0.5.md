## hey

👋 Hey again, this is a summary of [Freya](https://github.com/marc2332/freya) v0.5, the next release of my Rust 🦀 GUI library. I made this blog post more focused and compact than the posts for previous releases. Hopefully it’s better this way.

This release has a strong focus on **stability, refinement and documentation**, with fixes and improvements across multi-window apps, async tasks, rendering accuracy, text editing and performance, alongside new guides and expanded API docs. But there are also some big additions, like **experimental web support** and **HTML rendering powered by Blitz**.

## Freya in the browser (experimental)

The new [`freya-web`](https://crates.io/crates/freya-web) backend runs Freya apps in the browser using WebAssembly (WASM) and paints the UI to a canvas element. It uses the same component model, layout and rendering APIs as desktop Freya apps, except for some multi-window APIs.

Try it below, or [open the demo full-size](/demo/).

## HTML rendering

[`freya-html`](https://crates.io/crates/freya-html), powered by [Blitz](https://github.com/DioxusLabs/blitz), replaces the experimental [WRY](https://crates.io/crates/wry)-based `freya-webview` integration. HTML and CSS are now rendered inside Freya's own rendering pipeline, without embedding a real browser.

It supports [inline documents and URLs](https://docs.rs/freya/0.5.0/freya/html/enum.HtmlSource.html), [navigation history](https://docs.rs/freya/0.5.0/freya/html/struct.HtmlHandle.html), [resource caching](https://github.com/marc2332/freya/pull/2367) and form interactions. Just to be clear, **it does not run JavaScript and is not a full browser.** Enable the `html` feature to use it.

<img loading="lazy" alt="HTML and CSS rendered by Blitz inside Freya, including a search form, checkboxes, radio buttons and links" src="/blog/0.5/html.png" width="750" height="710">

See the [HTML example](https://github.com/marc2332/freya/blob/0.5/examples/feature_html/src/main.rs) for the app shown above.

## Important changes

### APIs

- Split [`Platform`](https://docs.rs/freya/0.5.0/freya/prelude/struct.Platform.html) into application-wide operations and [`PlatformWindow`](https://docs.rs/freya/0.5.0/freya/prelude/struct.PlatformWindow.html) for individual windows.
- Renamed `spawn_forever` to [`spawn_in_window`](https://docs.rs/freya/0.5.0/freya/prelude/fn.spawn_in_window.html) for tasks that live as long as their window, and added [`spawn_global`](https://docs.rs/freya/0.5.0/freya/prelude/fn.spawn_global.html) for tasks independent of any window. [`spawn`](https://docs.rs/freya/0.5.0/freya/prelude/fn.spawn.html) remains tied to its component.
- Added [shared global contexts](https://docs.rs/freya/0.5.0/freya/prelude/struct.GlobalContexts.html) for state such as [query storage](https://crates.io/crates/freya-query) and [internationalization](https://crates.io/crates/freya-i18n) across windows, plus [global effects](https://docs.rs/freya/0.5.0/freya/prelude/struct.Effect.html#method.create_global). [`LaunchConfig::with_global_context`](https://docs.rs/freya/0.5.0/freya/prelude/struct.LaunchConfig.html#method.with_global_context) and [`WindowConfig::with_root_context`](https://docs.rs/freya/0.5.0/freya/prelude/struct.WindowConfig.html#method.with_root_context) provide shared and per-window contexts explicitly.
- Made [`use_future`](https://docs.rs/freya/0.5.0/freya/prelude/fn.use_future.html) reactive. State read in its callback before the async block becomes a dependency, restarting the task when it changes.
- Added [`WritableSetter`](https://github.com/marc2332/freya/pull/2446) for routing component edits through a callback that can transform or reject them.
- Added [query mocking](https://github.com/marc2332/freya/pull/2083) and support for [disabling queries with `None` keys](https://github.com/marc2332/freya/pull/2114) in [`freya-query`](https://crates.io/crates/freya-query). Fixed [cache-clearing races](https://github.com/marc2332/freya/pull/2149) and [borrows held across async work](https://github.com/marc2332/freya/pull/2208).

### Performance

- Improved [element diffing](https://github.com/marc2332/freya/pull/2167).
- Added [mouse-move event coalescing](https://github.com/marc2332/freya/pull/2472) and optimized [event processing in Ragnarok](https://github.com/marc2332/freya/pull/2463).
- Reduced [idle work](https://github.com/marc2332/freya/pull/2254), [cached clip areas](https://github.com/marc2332/freya/pull/2188), removed [unnecessary opacity layers](https://github.com/marc2332/freya/pull/2210) and made [layout scaling incremental](https://github.com/marc2332/freya/pull/2184).
- Reworked the [`freya-metrics-plugin`](https://crates.io/crates/freya-metrics-plugin) overlay with [async task metrics](https://github.com/marc2332/freya/pull/2033) and [window dimensions](https://github.com/marc2332/freya/pull/2346). Expanded [layout](https://github.com/marc2332/freya/pull/2184), [reconciliation](https://github.com/marc2332/freya/pull/2318) and [painting benchmarks](https://github.com/marc2332/freya/pull/2357).

### Rendering

- Added [software-only builds](https://github.com/marc2332/freya/pull/2081) and [renderer preferences](https://docs.rs/freya/0.5.0/freya/prelude/struct.WindowConfig.html#method.with_renderer). Improved [backend selection and fallback](https://github.com/marc2332/freya/pull/2433), including Linux Wayland systems with multiple GPUs.
- Shared the [Vulkan context between windows](https://github.com/marc2332/freya/pull/2301) and added [manual frame throttling](https://github.com/marc2332/freya/pull/2417) for software rendering across platforms.
- Replaced the separate `canvas()` element with [`RenderCallback`](https://docs.rs/freya/0.5.0/freya/prelude/struct.RenderCallback.html) fills. Callbacks can [paint backgrounds](https://github.com/marc2332/freya/pull/2327) and [customize text paint](https://github.com/marc2332/freya/pull/2397) through the same API.
- Added [runtime font loading](https://docs.rs/freya/0.5.0/freya/prelude/struct.Platform.html#method.load_font), [font features](https://github.com/marc2332/freya/pull/2255) and [letter spacing](https://github.com/marc2332/freya/pull/2209). Improved [variable-font weights](https://github.com/marc2332/freya/pull/2310) and [platform-specific text gamma and contrast](https://github.com/marc2332/freya/pull/2314).
- Added [image blur](https://github.com/marc2332/freya/pull/2307), [image snapping](https://github.com/marc2332/freya/pull/2137), [per-element cursor styling](https://github.com/marc2332/freya/pull/2089) and [custom animation easing functions](https://github.com/marc2332/freya/pull/2363).

### Components

- Added [smooth scrolling](https://github.com/marc2332/freya/pull/2217), [touch dragging](https://github.com/marc2332/freya/pull/2216) and better [Linux touchpad scrolling](https://github.com/marc2332/freya/pull/2421). Scrollbars can be [customized](https://github.com/marc2332/freya/pull/2298) or [kept visible](https://github.com/marc2332/freya/pull/2386), and virtualized lists support [per-item sizes](https://github.com/marc2332/freya/pull/1985).
- Added [multiline inputs](https://github.com/marc2332/freya/pull/2192) and improved [wrapped-line navigation](https://github.com/marc2332/freya/pull/2176), [whole-word selection dragging](https://github.com/marc2332/freya/pull/2349), [Home/End](https://github.com/marc2332/freya/pull/2134) and [Ctrl+Backspace/Delete handling](https://github.com/marc2332/freya/pull/2064). Fixed [cursor placement](https://github.com/marc2332/freya/pull/2177) and [scrolling during text selection](https://github.com/marc2332/freya/pull/2453).
- Made [tables](https://github.com/marc2332/freya/pull/2270), [tooltips](https://github.com/marc2332/freya/pull/2056), [calendars](https://github.com/marc2332/freya/pull/2339) and [resizable panels](https://github.com/marc2332/freya/pull/2412) more customizable. Added [adaptive popup sizing](https://github.com/marc2332/freya/pull/2245) and [slider steps](https://github.com/marc2332/freya/pull/2145).
- Added [code editor options](https://github.com/marc2332/freya/pull/2228) for read-only mode, gutters, whitespace markers, line height, cursor mode and external scroll controllers in [`freya-code-editor`](https://crates.io/crates/freya-code-editor).
- Added [`Lazy`](https://docs.rs/freya/0.5.0/freya/components/struct.Lazy.html) for mounting content when it becomes visible, and an [`on_visible`](https://github.com/marc2332/freya/pull/1997) event for custom visibility handling.
- Moved [`freya-terminal`](https://crates.io/crates/freya-terminal) to [`rio-vt`](https://crates.io/crates/rio-vt) and added [custom terminal backends](https://github.com/marc2332/freya/pull/2238). Improved [focus reporting](https://github.com/marc2332/freya/pull/2080) and [font fallback](https://github.com/marc2332/freya/pull/2093).

### Internals

- Fixed reconciliation of [keyed components](https://github.com/marc2332/freya/pull/2425) and [mixed insertions and reordering](https://github.com/marc2332/freya/pull/2259).
- Improved [AccessKit action handling](https://github.com/marc2332/freya/pull/2379), [text announcements](https://github.com/marc2332/freya/pull/2189), [initial focus](https://github.com/marc2332/freya/pull/2423) and [pointer handling](https://github.com/marc2332/freya/pull/2350).
- Extracted [`tiny-diff`](https://crates.io/crates/tiny-diff), [`tiny-notify`](https://crates.io/crates/tiny-notify) and [`tiny-cache`](https://crates.io/crates/tiny-cache). Added `no_std` support to [Torin](https://crates.io/crates/torin), [Pathgraph](https://crates.io/crates/pathgraph) and [Ragnarok](https://crates.io/crates/ragnarok).
- Dropped the [GTK and libxdo dependencies from tray support](https://github.com/marc2332/freya/pull/2460).

Browse the [full changes](https://github.com/marc2332/freya/compare/3397d8d6...0.5) or the [examples](https://github.com/marc2332/freya/tree/0.5/examples) for more details.

## Documentation

The docs have also grown, with new guides and clearer explanations of existing APIs:

- Added [Building your first app](https://docs.rs/freya/0.5.0/freya/_docs/building_an_app/index.html), a step-by-step todo app tutorial covering state, reusable components, filtering and testing with `freya-testing`.
- Added an [optimization guide](https://docs.rs/freya/0.5.0/freya/_docs/optimizing/index.html) covering feature selection, renderer preferences, GPU cache limits, metrics and image viewers.
- Added guides for [fonts](https://docs.rs/freya/0.5.0/freya/_docs/fonts/index.html), including embedding and runtime loading, and [borderless windows](https://docs.rs/freya/0.5.0/freya/_docs/borderless/index.html).
- Improved the [UI and components guide](https://docs.rs/freya/0.5.0/freya/_docs/ui_and_components/index.html), clarified [extending components with builder traits](https://docs.rs/freya/0.5.0/freya/_docs/extending_components/index.html), and expanded the layout docs for [flex sizing](https://github.com/marc2332/freya/pull/2439) and [`Size::Fill`](https://github.com/marc2332/freya/pull/2462).
- Expanded the [events guide](https://docs.rs/freya/0.5.0/freya/_docs/events/index.html) with propagation, default behavior, ordering, global events, multi-press combos and exposing events from components.
- Improved docs for [contexts and global contexts](https://github.com/marc2332/freya/pull/2438), [async task lifetimes](https://docs.rs/freya/0.5.0/freya/_docs/_async/index.html), [`Effect`](https://github.com/marc2332/freya/pull/2377), [`Platform`](https://github.com/marc2332/freya/pull/2294) and [`AnimationClock`](https://github.com/marc2332/freya/pull/2481).
- Expanded the [router docs](https://github.com/marc2332/freya/pull/2313), reorganized the [radio state-management docs](https://github.com/marc2332/freya/pull/2428), and documented [custom elements](https://github.com/marc2332/freya/pull/2311).
- Added [Working with AI](https://docs.rs/freya/0.5.0/freya/_docs/ai/index.html), linking to [llms.txt](/llms.txt) and an installable [Freya skill](https://github.com/marc2332/freya/tree/0.5/skills/freya) for coding assistants. Updated the development setup, platform and web example instructions, and reorganized the contributing guide's crate list.

## Sanctum

I've also been working on [Sanctum](https://mespin.me/posts/sanctum), my Linux desktop environment written in Rust, which I've been daily driving for around six months.

All its UI is built with Freya, from the settings app, file explorer, system monitor and image viewer to the dock, control panel, notifications and app switcher. It also has its own Wayland compositor.
